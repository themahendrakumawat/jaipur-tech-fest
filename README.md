# Jaipur Tech Fest 2026 — Milestone 1 Project

A responsive, accessible event microsite built as part of the Full Stack + AI Engineering Program.

## 📌 Project Overview
Jaipur Tech Fest 2026 is a 3-day technology and innovation festival bringing together developers, designers, and tech enthusiasts.

## 📄 Pages Included
1. **Home:** Hero section with event date, venue, and countdown highlight strip.
2. **Schedule / Lineup:** Day-wise grid timeline of events and talks.
3. **Speakers / Performers:** Card grid featuring keynote speakers and industry experts with photos.
4. **Register:** Accessible registration form with ticket type radio buttons and T&C checkbox.

## 🛠️ Tech Stack
- HTML5 (Semantic Tags)
- Tailwind CSS (Utility-first styling)
- JavaScript
- Git & GitHub
